# Lab 3 – Python Automation with Copilot

## Scenario

You will extend the PowerShell automation from Lab 1 by building a lightweight Python service that ingests disk audit data, enriches it with business metadata, and publishes insights for downstream YAML/Ansible workflows.

## Learning Goals

- Use Copilot to scaffold Python scripts and refactor them into reusable modules.
- Parse and validate structured data generated by PowerShell tooling.
- Expose automation results through REST and CLI interfaces ready for CI/CD integration.

## Prerequisites

- Python 3.10+ with `pipx` or virtual environments.
- Packages: `pydantic`, `rich`, `typer`, `fastapi`, `uvicorn` (generate requirements with Copilot).
- Outputs from Lab 2 – PowerShell Automation (`../Lab1_PowerShell/logs/*.json`).

## Exercise 1 – Data Model & Validation (30 min)

1. Prompt Copilot: "Create a Python `pydantic` model that matches the disk report schema from Lab 1 and enforces free space >= 0."
2. Load sample JSON and validate a list of `DiskReport` items, surfacing validation errors.
3. Ask Copilot to add typed helper functions for translating percentage thresholds into severity labels.

## Exercise 2 – CLI Summarizer (25 min)

1. Generate a `typer` CLI that accepts a path to the JSON logs and prints a colorized summary via `rich` tables.
2. Add optional arguments (`--critical-threshold`, `--warn-threshold`, `--output yaml`).
3. Invoke Copilot Chat to convert the CLI output structures into YAML for Lab 4 consumption.

## Exercise 3 – RESTful Insights API (35 min)

1. Use Copilot to scaffold a `FastAPI` app exposing endpoints `/health`, `/reports`, and `/reports/{computerName}`.
2. Cache processed results in memory; ensure responses include severity and timestamps.
3. Add automated tests with `pytest` verifying the API routes and validation logic.

## Exercise 4 – Packaging & Handoff (20 min)

1. Prompt Copilot to generate a `pyproject.toml` or `requirements.txt` plus a `Makefile` task for running tests and linting (`ruff`, `pytest`).
2. Produce a `Dockerfile` skeleton that runs the API; note how it can be invoked from GitHub Actions in Lab 4.
3. Document Copilot prompt/response highlights for retrospective analysis.

## Copilot Prompt Sampler

- "Explain how the generated validator handles missing properties."
- "Refactor this FastAPI route to reuse the enrichment helper."
- "Convert this Python severity dictionary back into PowerShell parameters."

## Validation Checklist

- [ ] `pydantic` models pass sample JSON validation without runtime errors.
- [ ] CLI prints summaries and can export YAML via Copilot-generated helper.
- [ ] API responds to `/health` and `/reports` with correct status codes.
- [ ] Test suite executes through `pytest` (green) and lint passes.

## Stretch Goals

- Generate an async client that streams results to Event Hub or Cosmos DB.
- Ask Copilot to draft Terraform resources that provision an Azure Container Apps environment for the API.
